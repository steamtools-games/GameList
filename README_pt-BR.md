## 🚀 Como Usar o SteamTools

1. **Encontre seu jogo**: Pesquise pelo nome do jogo ou insira o Steam App ID em [SteamTools.games](https://steamtools.games/pt-BR).
2. **Baixe o pacote**: Clique em **Baixar ZIP** para receber `{appId}_public.lua`, `key.vdf` e o guia.
3. **Coloque os arquivos**: Copie `.lua` e `key.vdf` para o diretório raiz de instalação do SteamTools.
4. **Reinicie o cliente**: Inicie o SteamTools e a Steam — o jogo aparecerá na sua biblioteca pronto para sincronização.
