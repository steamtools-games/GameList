## 🚀 Comment Utiliser SteamTools

1. **Trouvez votre jeu** : Recherchez par nom ou saisissez l'App ID Steam sur [SteamTools.games](https://steamtools.games/fr).
2. **Téléchargez le pack** : Cliquez sur **Télécharger ZIP** pour obtenir `{appId}_public.lua`, `key.vdf` et les instructions.
3. **Placez les fichiers** : Copiez `.lua` et `key.vdf` dans le répertoire d'installation de SteamTools.
4. **Redémarrez le client** : Lancez SteamTools et Steam — le jeu apparaîtra dans votre bibliothèque.
